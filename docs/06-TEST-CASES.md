실행: `npm test` (vitest). 위치: `tests/*.test.ts`. 엔진은 React와 분리되어 있어 Node에서 바로 검증한다.

## D. 인력 부족
| ID | 케이스 | 기대 |

## I. 밸런스 점검 (자동 스크립트)
`npm run balance` — 업종 × 전략(무작위 100회 시드)로 시뮬레이션하여 생존율을 출력한다. 목표 범위는 "합리적 전략 70% 안팎 생존, 방치 전략 대부분 파산". 수치는 가정이므로 수업 의도에 맞게 `templates.ts`에서 조정한다.
