# 화면 목록

단일 페이지 앱이다. `GameApp`이 저장된 게임 상태의 `phase`에 따라 화면을 바꾼다. 상단 공통 영역에 진행 상태와 지표가 항상 보인다.

| ID | 화면 | 진입 조건 | 주요 요소 | 이동 |
|---|---|---|---|---|
| S1 | 시작·설정 | 저장된 게임 없음 | 기업명, 사업 아이디어, 업종, 고객 유형, 대상 고객, 수익모델, 초기 자본(프리셋+직접입력), 창업 멤버 수, 진행 모드, 교육용 가정 안내 | → S2 |
| S1b | (구현 변경) | 저장된 게임 있음 | 별도 화면 없이 저장된 화면으로 자동 복귀. 초기화는 헤더의 "처음부터" 버튼(확인 대화상자) | → 저장된 화면 |
| S2 | 창업 완료·초기 상태 | 설정 직후(sim.month = 0, 결정 0건) | 초기 지표 6종, 인력·월 고정비·런웨이, 템플릿 가정값 설명 | → S3 |
| S3 | 이벤트 | phase = event | 단계·연차·진행(n/N), 상황 설명, 토론 질문, 대안 카드(비용·조건만), 선택 근거 입력, 반대 의견 입력, 결정 확정 | → S4 |
| S4 | 결정 결과 | phase = outcome | 결과 해설, 결정 직후 지표 변화, 이후 N개월 경과 변화, 경고(현금 부족·인력 부족), 학습 포인트 | → S3 / S5 / S6 |
| S5 | 연차 마무리 | 한 해 종료 시 S4의 "계속" 안에서 표시 | 연차 요약 한 줄, 다음 단계 안내 | → S3 |
| S6 | 최종 보고서 | phase = finished | 종합 점수·등급, 6개 지표 추이 차트, 지표별 점수, 주요 전환점, CB Insights 실패요인별 대응, 토론 기록 목록, 학습 질문, 내보내기(마크다운·JSON), 인쇄 | → S1 (초기화) |
| M1 | 초기화 확인 모달 | 어디서든 "초기화" | 되돌릴 수 없음을 알리는 확인 | → S1 |
| M2 | 결정 기록 패널 | 어디서든 "결정 기록" | 지금까지의 결정·근거 목록 | 닫기 |

## 공통 영역
- **런웨이 띠**: 현금 ÷ 월 순소진으로 남은 개월 수를 막대로 보여준다. 3개월 미만이면 경고색, 현금이 음수면 위기 문구.
- **지표 줄**: 매출(월), 현금, 고객 수, 제품 품질, 팀 사기, 평판. 각 지표에 직전 이벤트 대비 변화량.
- **저장 표시**: "자동 저장됨 · 방금" 상태 문구.
- **교육용 가정 안내**: 푸터에 항상 한 줄.

## 상태 화면 처리
| 상황 | 표시 |
|---|---|
| 현금 < 0 | 상단에 위기 배너("2개월 연속 마이너스면 파산"), 현금이 필요한 대안은 비활성 |
| 인력 부족(가동률 > 100%) | 지표 줄에 "인력 부족" 배지, 결과 화면에 품질·사기 하락 원인으로 표시 |
| 대안 조건 미충족 | 대안 카드는 보이되 비활성, 사유 문구("현금 부족", "인력 4명 이상 필요" 등) |
| 파산 | S4에서 파산 안내 → S6 보고서(파산 사유 포함) |

## 접근성·반응형
- 360px 폭 기준 1열, 768px 이상에서 지표 6열 / 대안 2열.
- 모든 버튼·입력은 키보드 포커스 링 표시, 상태는 색뿐 아니라 문구로도 표시.
- `prefers-reduced-motion`이면 애니메이션 제거.
